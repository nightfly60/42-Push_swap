## 📘 Overview
**Push_swap** is an algorithmic challenge where you must sort a stack of integers using only a restricted set of stack operations.  
The goal is to produce the **shortest possible sequence of instructions** to achieve a sorted result, testing both your **logic** and your **optimization skills**.  

For this project, I implemented the stacks using **linked lists**, allowing **dynamic memory management**, **fast insertions/removals**, and a **clear structure** for stack manipulation.

---

## 🎯 Project Goals
- Develop and implement **efficient sorting algorithms**  
- Understand and apply **algorithmic complexity** concepts  
- Practice **stack manipulation** and **data structure operations**  
- Optimize performance to minimize the number of moves  
- Strengthen debugging, testing, and code optimization techniques  

---

## 🧩 Core Concepts
- **Stacks (a and b)**: two data structures implemented as **linked lists**  
- **Operations**: limited set of moves (`sa`, `pb`, `ra`, etc.) to reorder stacks  
- **Algorithm design**: choose the best sorting strategy depending on input size  
- **Optimization**: reduce instruction count to meet strict performance benchmarks  

---

## ⚙️ Mandatory Program
- **Program name**: `push_swap`
- **Language**: C
- **Data structure**: linked lists
- **Description**:
  Takes a list of integers and outputs the shortest sequence of stack operations required to sort them.

## 📘 Aperçu
**Push_swap** est un défi algorithmique consistant à trier une pile d’entiers à l’aide d’un ensemble limité d’opérations.  
L’objectif est de produire la **séquence d’instructions la plus courte possible** pour obtenir un résultat trié, en testant à la fois la **logique** et l’**optimisation**.  

Pour ce projet, j’ai implémenté les piles avec des **listes chaînées**, permettant une **gestion dynamique de la mémoire**, des **insertions/suppressions rapides**, et une **structure claire** pour la manipulation des piles.

---

## 🎯 Objectifs du Projet
- Développer et implémenter des **algorithmes de tri efficaces**  
- Comprendre et appliquer les principes de **complexité algorithmique**  
- S’exercer à la **manipulation de piles** et aux **structures de données**  
- Optimiser le programme pour réduire le nombre d’opérations  
- Renforcer les compétences en **débogage**, **optimisation** et **qualité du code**  

---

## 🧩 Concepts Clés
- **Piles (a et b)** : deux structures de données implémentées sous forme de **listes chaînées**  
- **Opérations** : ensemble limité d’actions (`sa`, `pb`, `ra`, etc.) pour réorganiser les piles  
- **Conception d’algorithmes** : choisir la stratégie la plus adaptée selon la taille des données  
- **Optimisation** : réduire le nombre d’instructions pour atteindre les performances attendues
